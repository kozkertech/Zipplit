1. Introduction 
This document defines the website scope and requirements for Zipplit — a hyperlocal, preservative-free 
food brand based in Kochi. It is written exclusively for the web development team and covers all pages, 
sections, UX requirements, functional specifications, and design system guidelines. 
The Zipplit website serves one primary purpose: to build market identity and brand awareness. It is a 
brand-first digital presence designed to communicate Zipplit's story, values, and offerings — and to 
convert visitors into customers via WhatsApp ordering and lead capture. 
Business financials, supply chain operations, and internal logistics are out of scope for this document. 
2. Website Goals 
The website is Zipplit's primary digital touchpoint for brand awareness and customer acquisition. Every 
decision — from page structure to content hierarchy — should serve these goals:

5. Functional Requirements 
5.1  WhatsApp Ordering Integration 
• Every 'Order Now' CTA must open a pre-filled WhatsApp message to the configured number 
• WhatsApp number stored globally — single point of update for the entire site 
• CTA placement: Hero section, product listings, footer, and sticky mobile bottom bar 
5.2  Lead Capture / Waitlist Form 
• Fields: Name, Phone Number, Area / Location 
• Submissions stored and optionally forwarded to admin email 
• Success confirmation message shown on submission 
• No login or user account required 
5.3  B2B Inquiry Form 
• Fields: Business Name, Contact Person, Phone, Business Type, Requirement Details 
• Submissions routed to dedicated business email address 
• Confirmation message shown on successful submission 
5.4  Category Navigation — Products Page 
• Horizontal scrollable tab bar (Swiggy-style UX) 
• Tabs: Snacks & Starters, Veg Meals, Non-Veg Meals, Combos, Frozen 
• Clicking a tab smooth-scrolls to or filters the relevant section

• CMS should support image uploads, rich text, and structured content types 
• CMS access credentials and roles to be configured for the Zipplit team before handoff 
6. Non-Functional Requirements 
6.1  Performance & Speed 
• Target page load under 3 seconds on 4G mobile connection 
• Core Web Vitals (LCP, FID, CLS) must pass Google's recommended thresholds 
• Images served in WebP format with responsive srcsets 
• Lazy loading on all below-fold images 
6.2  Mobile Responsiveness 
• Mobile-first design — all layouts designed for small screens first 
• Sticky WhatsApp CTA button visible on mobile at all times 
• Touch-friendly tap targets (minimum 44px) 
• Tested on Android Chrome and iOS Safari 
6.3  Technical SEO 
• Semantic HTML5 structure throughout all pages 
• Unique meta titles and meta descriptions for every page 
• Open Graph and Twitter Card tags for social sharing 
• Structured data markup (schema.org LocalBusiness, Menu, Organization) 
• XML sitemap and robots.txt configured correctly 
• Canonical URLs set on all pages 
• Clean URL structure — no query strings for main pages 
6.4  Accessibility 
• All images must have descriptive alt text

7. Design & Branding System 
All design decisions must strictly follow the Zipplit brand system defined below. This is not a 
suggestion — it is the required design specification for the website. 
7.1  Brand Purpose 
The Zipplit website is a brand-first experience. Its visual language must communicate: clean, fresh, 
trustworthy, modern, and rooted in Kerala. Every color, font, and layout choice should reinforce this 
positioning. 
7.2  Primary Typeface 
• Typeface: Nunito (Google Fonts — free & web-safe) 
• Use across all headings, body text, buttons, labels, and UI elements 
• Weights in use: Regular (400), SemiBold (600), Bold (700), ExtraBold (800) 
• No other typeface should be introduced without explicit approval

7.4  Color Usage Rules 
• Deep Teal (#0A4849) — Primary backgrounds, section headers, nav bar, key UI elements 
• Fresh Lime (#9BCF55) — CTA buttons, highlights, dividers, badge accents, hover states 
• Pure White (#FFFFFF) — Page backgrounds, card surfaces, text on dark backgrounds 
• Bold Black (#000000) — High-impact headings and strong contrast areas 
• Charcoal Gray (#333333) — All body copy and paragraph text 
• Stone Gray (#5B5B5B) — Supporting text, labels, captions, metadata 
• WhatsApp green (#25D366) — Used exclusively for WhatsApp ordering CTAs 
7.5  Visual Style 
• Tone: Clean, modern, trustworthy, fresh, and rooted in Kerala culture 
• Imagery: Real food photography strongly preferred over stock illustrations or icons 
• Layout: Generous white space, clear visual hierarchy, uncluttered sections 
• Icons: Minimal line-style icons only — no heavy or decorative icon sets 
• Buttons: Rounded corners — Fresh Lime for primary actions, Deep Teal for secondary 
8. Content Requirements 
The following must be provided by the Zipplit team before development handoff. Development cannot 
be finalized without these assets. 
• Brand logo — SVG and high-resolution PNG (on transparent background) 
• Food photography for all menu items and meal categories 
• Final menu list with item names, short descriptions, and dietary tags 
• Pricing details (if to be displayed on the website) 
• Customer testimonials — name, quote, and optional photo 
• WhatsApp Business number (configured and active) 
• Email address for form submissions (general + B2B) 
• Social media handles — Instagram, Facebook, and any others 
• Service area details — specific areas or pincodes within Kochi served 
• Brand guidelines / logo usage rules if separately documented
